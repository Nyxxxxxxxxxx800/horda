# Horda - mod Fabric para Minecraft 26.2

NPCs com skins variadas que nascem parados e correm atras de voce.

Comandos:
- /horda spawn <quantidade> [raio]
- /horda start
- /horda stop
- /horda clear

Para editar skins, % de saltadores, velocidade etc: abra
src/main/java/com/horda/HordaMod.java (secao CONFIGURACAO).

O .jar e gerado pelo GitHub Actions (aba Actions > Artifacts).
Precisa de Fabric Loader + Fabric API 26.2 instalados no jogo.
